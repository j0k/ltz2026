# Если что-то не работает

| что видно | что сделать |
|---|---|
| «файл сжат и не разжимается» | выгрузите снимок с денситометра без сжатия |
| «модальность CT/MR — это не денситометрия» | это снимок другого исследования, его программа не проверяет |
| «не удалось прочитать файлы» | проверьте, что файлы не открыты в другой программе и есть права на папку |
| внизу красная строка «Движок анализа не отвечает» | подождите несколько секунд: программа сама перезапустит движок; если не помогло — закройте и откройте окно |
| окно не открывается | запустите «Kostik — проверка установки» из меню Пуск или `kostik --selftest` в терминале |
| модель не скачивается | проверьте интернет; или «Импорт из файла» на странице Моделей |

Журнал ошибок — файл `dxaqc.log` в папке данных (путь в Настройках). Пришлите его разработчикам — контакты в «О программе».

## Командная строка

В папке установки (в Windows — `C:\Program Files\Kostik-1.0\`, в Linux — команда `kostik`) работают команды:

| команда | что делает |
|---|---|
| `Kostik.exe --help` | справка по всем параметрам |
| `Kostik.exe --version` | версия программы и анализа, Python, путь установки |
| `Kostik.exe --author` | авторы, команда, контакты |
| `Kostik.exe --mcp` | как подключить ИИ-ассистента: готовая настройка для Claude Desktop и список инструментов |
| `Kostik.exe --verbose` | **подробный журнал запуска**: система, папки, каждая библиотека с временем, WebView2, порт, анализ фантома, запуск движка и окна |
| `Kostik.exe --selftest` | проверка установки (вместе с `--verbose` — с подробным журналом) |
| `Kostik-cli.exe --check папка` | **проверка из консоли**: описание по каждому снимку прямо в консоль, окно и браузер не нужны |
| `Kostik-cli.exe --check папка --json` | то же в JSON — для сценариев и ИИ-агентов; `--out папка` складывает таблицы и разметку в папку |
| `Kostik-cli.exe --results` | описание последней проверки; `--results номер` — названной; `--runs` — список проверок |
| `Kostik.exe --show-all-hosts` | на каких адресах может слушать сервер программы: этот компьютер, все интерфейсы, каждый интерфейс по имени |
| `Kostik.exe --host 0.0.0.0` | открыть программу по сети; по умолчанию `127.0.0.1` — только этот компьютер. Входа по паролю в программе нет |

`Kostik.exe` — оконная программа: консоль не ждёт её завершения, поэтому приглашение появляется раньше ответа.
В сценариях и там, где нужен код возврата, пользуйтесь `Kostik-cli.exe` — параметры те же.

### Проверка из консоли

`Kostik-cli.exe --check` печатает всё, что показывает страница проверки: область, вердикт, нарушение, пояснение, измерения
и путь к картинке разметки на диске. Открывать окно или страницу `http://127.0.0.1` не нужно.

- Окно программы открыто — проверку выполняет оно: она видна в строке состояния и в истории; `--open` сразу её покажет.
- Окна нет — на время команды поднимается движок без окна и гасится после ответа.

Код возврата: 0 — нарушений нет, 1 — есть снимки с нарушением, 2 — нет таких файлов, 3 — проверка не удалась
или часть снимков не обработана.

### Claude Code

Плагин Kostik для Claude Code ставится двумя командами: `/plugin marketplace add https://github.com/j0k/ltz2026.git`
и `/plugin install kostik@ltz2026`. После этого снимки проверяются прямо в разговоре: `/kostik:check папка`.

Журнал `--verbose` печатается в консоль и сохраняется в файл `dxaqc-verbose.log` в папке данных — пришлите его
разработчикам, если программа не запускается.
