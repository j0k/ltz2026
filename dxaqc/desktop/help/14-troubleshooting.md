# Если что-то не работает

| что видно | что сделать |
|---|---|
| «файл сжат и не разжимается» | выгрузите снимок с денситометра без сжатия |
| «модальность CT/MR — это не денситометрия» | это снимок другого исследования, его программа не проверяет |
| «не удалось прочитать файлы» | проверьте, что файлы не открыты в другой программе и есть права на папку |
| внизу красная строка «Движок анализа не отвечает» | подождите несколько секунд: программа сама перезапустит движок; если не помогло — закройте и откройте окно |
| окно не открывается | запустите «Kostik — проверка установки» из меню Пуск или `kostik --selftest` в терминале |
| модель не скачивается | проверьте интернет; или «Импорт из файла» на странице Моделей |

Журнал ошибок — файл `dxaqc.log` в папке данных (путь в Настройках). Пришлите его разработчикам — контакты в «О программе».

## Командная строка

В папке установки (в Windows — `C:\Program Files\Kostik-1.0\`, в Linux — команда `kostik`) работают команды:

| команда | что делает |
|---|---|
| `Kostik.exe --help` | справка по всем параметрам |
| `Kostik.exe --version` | версия программы и анализа, Python, путь установки |
| `Kostik.exe --author` | авторы, команда, контакты |
| `Kostik.exe --mcp` | как подключить ИИ-ассистента: готовая настройка для Claude Desktop и список инструментов |
| `Kostik.exe --verbose` | **подробный журнал запуска**: система, папки, каждая библиотека с временем, WebView2, порт, анализ фантома, запуск движка и окна |
| `Kostik.exe --selftest` | проверка установки (вместе с `--verbose` — с подробным журналом) |

Журнал `--verbose` печатается в консоль и сохраняется в файл `dxaqc-verbose.log` в папке данных — пришлите его
разработчикам, если программа не запускается.
