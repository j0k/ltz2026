# Kostik — демонстрационный сценарий

Показ занимает 5–7 минут: основной сценарий — 2 минуты, остальное — кейсы по вопросам экспертов.
Всё показывается на стенде https://ltz2026.ru или локально (`./serve.sh`, http://localhost:8000). Готовые
примеры на главной — исследования обучающего набора организатора с оценкой экспертов; для показа вне закрытого
контура есть синтетические фантомы в приложении для компьютера.

## Основной сценарий (2 минуты)

| шаг | действие | что сказать |
|---|---|---|
| 1 | Главная → **«или выберите готовый пример»** → **«Посторонний предмет»** | Врач загружает исследование сразу после снимка — перетащить DICOM или zip |
| 2 | Дашборд: сводка и галерея снимков | За секунду: 3 снимка, область каждого, красная рамка — брак, причина под снимком |
| 3 | Нажать на снимок поясницы с красной рамкой | Атлас: позвонки Th12–L5, ось, гребни подвздошных костей, предмет в рамке |
| 4 | Переключатель **«атлас → снимок»** | Врач видит и исходный снимок без разметки |
| 5 | Пояснение: **граф → текст** | Решение объяснимо: «контраст пятна против нормы 55 → посторонний предмет» |
| 6 | Сравнение с экспертами на карточке | Все три вердикта — поясница и оба бедра — совпали с оценкой экспертов организатора |
| 7 | **Таблица XLSX** | Формат п. 2.5 ТЗ: строка на снимок, коды нарушений |

## Кейсы

| кейс | как показать | что демонстрирует |
|---|---|---|
| Качественное исследование | пример **«Качественное исследование»** | все проверки ✓, зелёные рамки; сервис не «перестраховывается» |
| Неполный охват | пример **«Неполный охват»** | гребни подвздошных костей не видны в нижних углах кадра |
| Наклон оси | пример **«Наклон оси»** | угол оси против допуска 5° на графе решения |
| Сколиоз | тот же пример или снимок с комментарием экспертов «сколиоз» | честное ограничение: изгиб позвоночника сервис может принять за наклон — об этом сказано в пояснении и в ограничениях |
| Бедро: укладка | пример **«Укладка бедра»** | модель по 47 признакам, вероятность брака против порога; вердикт по бедру — подсказка |
| Бедро: поля ROI | пример **«Поля зоны интереса»** | мало места вокруг шейки бедра |
| Посторонний предмет или ребро | пример **«Для теста»** | два симметричных пятна вверху: выноска «посторонний предмет? или ребро — проверьте» — сервис отмечает сомнение |
| Чужой файл | загрузить JPG-снимок, КТ или МРТ | отказ с причиной и описание: что за снимок, проекция, надписи и водяные знаки на картинке |
| Битый архив | загрузить повреждённый zip вместе с нормальными файлами | строка отказа по архиву, остальные файлы проверены |
| Пакетная обработка | `./run.sh "Для теста.zip" out` | контейнер без сети, 3 снимка за ~2 секунды, таблица и архив разметки |
| Работа без интернета | приложение для компьютера (`.exe`/`.deb`) | та же проверка на ноутбуке врача, снимки не покидают компьютер |

**Эндопротез и перелом.** В обучающем наборе организатора таких снимков нет, поэтому отдельных правил для них
нет. Металлический эндопротез вне позвоночного столба будет найден как посторонний предмет (яркое пятно,
контрастное к окружению); перелом сервис не ищет — это диагностическая задача, а не контроль качества.

## Ответы на частые вопросы

- **Сколько времени?** 0,3 с на снимок на 2 ядрах без видеокарты; весь обучающий набор — 90 с.
- **Точность?** Позвоночник ROC-AUC 0,75 (посторонние предметы 0,85, охват 0,88), бедро 0,66 — кросс-валидация
  по исследованиям с 95 % интервалами.
- **Данные уходят наружу?** Нет: контейнер запускается без сети, модели — внутри образа.
- **Что если снимок не DXA?** Строка `Failure` с понятной причиной, остальные файлы проверяются.
