# Приёмка Kostik 1.0-Beta на людях (#169)

Участник видит программу впервые. Ведущий не подсказывает, только записывает: время, где человек застрял,
что сказал вслух. 2–3 участника, лучше один — врач или рентгенолаборант.

Перед началом: чистый компьютер (Windows 10/11 или Ubuntu), ссылка https://ltz2026.ru/download,
папка с 2–3 обезличенными исследованиями DICOM.

| № | задача участнику | успех | время, мин | застрял / замечания |
|---|---|---|---|---|
| 1 | Скачайте и установите программу для вашего компьютера | программа в меню «Пуск» / приложений | | |
| 2 | Убедитесь, что программа установилась правильно | нашёл «Проверка установки», увидел «ВСЁ В ПОРЯДКЕ» | | |
| 3 | Посмотрите, как программа работает, без своих снимков | открыл демо или готовый пример | | |
| 4 | Проверьте снимки из папки | открыл папку, дошёл до дашборда | | |
| 5 | Найдите снимок с нарушением и скажите, что с ним не так | назвал нарушение и область | | |
| 6 | Покажите, почему программа так решила | открыл граф или текст пояснения, назвал измерение и норму | | |
| 7 | Посмотрите этот снимок в 3D и вернитесь к рентгену | переключил «Рентген ⇄ 3D» | | |
| 8 | Сохраните таблицу результатов на рабочий стол | файл XLSX открылся в Excel / LibreOffice | | |
| 9 | Включите озвучку пояснения | скачал голос в «Моделях» и услышал озвучку | | |
| 10 | Подключите программу к ИИ-ассистенту (если он есть) | скопировал настройку, «Проверить связь» — зелёный | | |

После задач — три вопроса: что было непонятно; чего не хватило; стал бы пользоваться и для чего.

Итог записать в тикет #169: время по задачам, блокеры (задача не решена без подсказки), список правок.
Приёмка пройдена, если нет блокеров в задачах 1–8.
