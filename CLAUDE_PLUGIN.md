# Kostik и Claude Code: установка плагина и проверка

Плагин подключает программу Kostik к Claude Code. После этого снимки денситометрии можно проверять прямо
в разговоре: «проверь снимки в такой-то папке» — и в ответ приходит область, вердикт, нарушение и пояснение
по каждому снимку. Открывать окно программы или страницу `http://127.0.0.1` не нужно.

Здесь — как поставить плагин и как убедиться, что он работает: шаг за шагом, с настоящими ответами программы
на снимках учебного набора организатора.

## Что нужно

| что | где взять |
|---|---|
| Kostik 1.0-Beta сборки `20260930` или новее | [Releases](https://github.com/j0k/ltz2026/releases) или https://ltz2026.ru/download |
| Claude Code | https://claude.com/claude-code |
| снимки DXA в формате DICOM | свои или учебный набор организатора |

Плагин саму программу не ставит. Ставьте Kostik в папку по умолчанию — `C:\Program Files\Kostik-1.0`.

## Установка

В Claude Code выполните две команды:

```
/plugin marketplace add https://github.com/j0k/ltz2026.git
/plugin install kostik@ltz2026
```

Перезапустите Claude Code.

Если раньше вы подключали Kostik вручную командой `claude mcp add kostik …`, уберите то подключение, иначе
инструменты будут в двух экземплярах:

```
claude mcp remove kostik -s user
```

Программа стоит не в папке по умолчанию — задайте путь переменной окружения и перезапустите Claude Code:

```
setx KOSTIK_CLI "D:\Программы\Kostik\Kostik-cli.exe"
```

В Linux плагин не нужен, сервер подключается одной командой: `claude mcp add kostik -- kostik --mcp-stdio`.

## Шаг 1. Программа отвечает сама

Сначала убедитесь, что работает сама программа, — без Claude Code. В PowerShell:

```powershell
& "C:\Program Files\Kostik-1.0\Kostik-cli.exe" --selftest
```

Ожидаемый ответ, код возврата 0:

```

  ✓ Папка данных: …
```

Важна последняя строка: **8 инструментов**. Если их 7 — стоит старая сборка, в ней нет инструмента `describe_run`.

## Шаг 2. Плагин подключён

В терминале:

```
claude mcp list
```

В списке должна быть строка:

```
plugin:kostik:kostik: C:\Program Files\Kostik-1.0\Kostik-cli.exe --mcp-stdio - ✔ Connected
```

То же видно внутри Claude Code по команде `/mcp`. Состав плагина показывает `claude plugin details kostik`:
один сервер MCP, навык `kostik` и три команды.

| команда | что делает |
|---|---|
| `/kostik:check <путь>` | проверить файл `.dcm`, папку или zip-архив |
| `/kostik:results [номер]` | результат уже сделанной проверки; без номера — последней |
| `/kostik:runs` | список последних проверок |

## Шаг 3. Проверка снимков из Claude Code

Возьмите папку одного исследования и напишите в Claude Code:

```
/kostik:check D:\снимки\наклон_оси
```

Можно и словами: «проверь снимки в папке D:\снимки\наклон_оси». Claude попросит разрешение на вызов инструмента
`analyze_paths` — разрешите.

Настоящий ответ Claude Code на исследовании из учебного набора — три снимка, у позвоночника наклон оси.
Проверка заняла 44 секунды, из них сам анализ — меньше секунды:

> **Итог:** 3 снимка — 2 годных, 1 с нарушением, не оценено 0, не обработано 0; одинаковых файлов не было.
>
> | Файл | Область | Вердикт | Нарушение |
> |---|---|---|---|
> | `00_CR000000.dcm` | поясничный отдел | нарушение | наклон оси позвоночника больше допуска |
> | `01_CR000001.dcm` | левое бедро | годен (подсказка модели) | — |
> | `02_CR000002.dcm` | правое бедро | годен (подсказка модели) | — |
>
> **Снимок с нарушением: `00_CR000000.dcm`**
>
> - **Наклон оси:** ось столба отклонена на **+7,7°** при допуске **±5°**, превышение 2,7°. Центр столба в нижней
>   трети смещён на 21 px относительно верхней.
> - **Охват снизу:** верхние края подвздошных костей видны в обоих нижних углах кадра.
> - **Посторонние предметы:** ярких пятен вне столба не найдено — контраст 41 при пороге 55.
> - **Не проверялось:** уровень Th12 у верхней границы кадра программа пока не оценивает.
>
> **Снимки бедра.** Вердикт по бедру выносит обученная модель, и это подсказка для проверки, а не окончательный
> вывод: по кросс-валидации её ROC-AUC около 0,66, обучена на 150 снимках.
>
> | Файл | Вероятность брака | Порог |
> |---|---|---|
> | `01_CR000001.dcm` | 0,12 | 0,38 |
> | `02_CR000002.dcm` | 0,20 | 0,38 |
>
> **Файлы** лежат в папке проверки: таблицы `results.xlsx` и `results.csv`, все картинки разметки `overlays.zip`.

Формулировки у Claude от раза к разу немного меняются, а числа, вердикты и нарушения — нет: их считает программа.

**Что проверить в ответе:**

1. числа совпадают с тем, что печатает сама программа (следующий раздел);
2. вердикт по бедру назван подсказкой, с вероятностью и порогом;
3. нет диагноза и клинических выводов;
4. нет ссылок на `http://127.0.0.1` — только пути к файлам на диске.

## Примеры на учебном наборе

Ниже — ответы самой программы, командой `Kostik-cli.exe --check <папка>`. Исследования взяты из учебного набора
организатора; для каждого случая — первое по порядку, где программа согласна с экспертом, и одно, где не согласна.
Папки переименованы, идентификаторы исследований и снимков в примеры не попали.

| пример | что отметил эксперт | что нашла программа | код возврата |
|---|---|---|---|
| 1. Без нарушений | нарушений нет | 3 снимка годны | 0 |
| 2. Наклон оси | ось отклонена больше 5° | наклон 7,7° при допуске 5° | 1 |
| 3. Посторонний предмет | предметы или артефакты | пятно вне столба, контраст 80 при пороге 55 | 1 |
| 4. Укладка бедра | укладка обоих бёдер | оба бедра: вероятность брака 0,85 и 0,86 | 1 |
| 5. Программа не согласна | ось отклонена больше 5° | наклон 3,4° — в пределах допуска, снимок годен | 0 |

### Пример 5. Программа не согласна с экспертом

Эксперт отметил наклон оси, программа его не нашла:

```
   область:   поясничный отдел
   вердикт:   ГОДЕН
   пояснение: …
              Ось столба отклонена на 3.4°, это в пределах допуска 5°.
   измерения: угол оси, ° — -3.4; допуск оси, ° — ±5; …
```

Такие случаи есть, и скрывать их незачем. Программа измеряет наклон прямой, проведённой через центры столба
вверху и внизу кадра; при изгибе позвоночника такая прямая может лечь почти вертикально. Поэтому вердикт
программы — повод посмотреть снимок, а не замена взгляду специалиста. Точность по каждому критерию —
в [README](README.md), раздел «Честное состояние».

В примере оставлен один снимок из трёх. В настоящем ответе вместо `%LOCALAPPDATA%` стоит полный путь, а вместо
многоточий — идентификаторы исследования и снимка из файла DICOM.

| поле | значения |
|---|---|
| `state` | `queued`, `running`, `done`, `error`, `cancelled` |
| `final` | `true` — итоговая таблица записана; `false` — проверка ещё идёт или оборвалась |

| `started_by` | `консоль`, `окно программы` или имя ассистента |

Ключ `--out папка` складывает таблицы и картинки разметки в указанную папку — пути в ответе ведут уже туда.

спросить итог и снимки с нарушением, например: «проверь папку и покажи только исследования с наклоном оси».

## Если что-то не работает

| что видно | что делать |
|---|---|
| `/plugin marketplace add` — `fatal: fetch-pack: invalid index-pack output` | слишком длинный путь к папке настроек Claude Code; в папке по умолчанию такого нет |
| `/kostik:check` — неизвестная команда | плагин не установлен или Claude Code не перезапущен |
| в `/mcp` сервер `kostik` с ошибкой | программа не установлена или стоит в другой папке — задайте `KOSTIK_CLI` |
| инструментов 7, а не 8 | старая сборка программы — поставьте новую |
| инструменты Kostik в двух экземплярах | осталось ручное подключение: `claude mcp remove kostik -s user` |
| «ИИ-ассистент выключен в приложении» | откройте Kostik → «ИИ-ассистент» → «Включить» |
| Claude не вызывает Kostik, а рассуждает сам | назовите программу прямо: «проверь в Kostik…» или дайте команду `/kostik:check` |
| проверка большой папки идёт дольше трёх минут | Claude получит номер проверки; результат — `/kostik:results <номер>` |

Подробный журнал запуска программы: `Kostik-cli.exe --verbose`.

## Данные и ограничения

- **Сама программа снимки никуда не отправляет.** Но результаты проверки, которые получает Claude, уходят в модель
  через интернет: область, вердикт, измерения, имена файлов, идентификаторы исследования. Снимки пациентов
  и данные организатора передавайте так только с разрешением.
- **Kostik не ставит диагноз** и не измеряет плотность кости. Он оценивает качество снимка.
- **Вердикт по бедру — подсказка модели**, её точность ниже, чем у проверок позвоночника.
- **В плагине нет токенов, паролей и личных данных**: только адрес запуска программы и текст подсказок.
  Это проверяет тест [`tests/test_plugin.py`](tests/test_plugin.py).
- Плагин рассчитан на Windows и на папку `C:\Program Files\Kostik-1.0`. Когда выйдет версия с другой папкой,
  путь в `plugins/kostik/.mcp.json` нужно будет поправить.
