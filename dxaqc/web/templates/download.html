Windows 10 и 11

  1. Скачайте .exe и запустите.
  2. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Предупреждение появляется, потому что у программы пока нет платной цифровой подписи.
  3. Следуйте мастеру установки: права администратора не нужны.
  4. Откройте DXA QC из меню «Пуск». Проверить установку — ярлык «Проверка установки».

Для администраторов: msiexec /i DXAQC-{{ rel.version }}.msi /qn — тихая установка на компьютер, msiexec /x … /qn — удаление. Окно использует встроенный в Windows Microsoft Edge WebView2.

Linux

  1. Скачайте .deb.
  2. Установите: sudo apt install ./dxaqc_{{ rel.version }}_amd64.deb — система доставит нужные пакеты окна (WebKitGTK).
  3. Откройте DXA QC из меню приложений или командой dxaqc.
  4. Проверка установки: dxaqc --selftest.

Ubuntu 22.04 и 24.04, Debian 12 (Python 3.10–3.12). Удаление: sudo apt remove dxaqc.
