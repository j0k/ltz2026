# Плагин Kostik для Claude Code

Проверка снимков денситометрии DXA программой Kostik прямо из Claude Code: область, вердикт, нарушение
и пояснение по каждому снимку. Окно программы и браузер для этого не нужны.

## Что нужно

Установленная программа Kostik 1.0-Beta или новее: https://ltz2026.ru/download. Плагин саму программу не ставит.

## Установка

В Claude Code:

```
/plugin marketplace add https://github.com/j0k/ltz2026.git
/plugin install kostik@ltz2026
```

Из папки с исходниками — то же, но в первой команде вместо адреса путь к папке репозитория.

После установки перезапустите Claude Code и проверьте командой `/mcp`: в списке должен быть сервер `kostik`.

## Команды

| команда | что делает |
|---|---|
| `/kostik:check <путь>` | проверить файл `.dcm`, папку или zip-архив и рассказать, что с каждым снимком |
| `/kostik:results [номер]` | результат уже сделанной проверки; без номера — последней |
| `/kostik:runs` | список последних проверок |

Можно и словами: «проверь снимки в папке D:\снимки\исследование» — Claude сам вызовет Kostik.

## Как это устроено

Плагин подключает сервер MCP программы: Claude Code сам запускает `Kostik-cli.exe --mcp-stdio` из папки программы.
Токен не нужен, окно программы может быть закрыто. Если окно открыто, проверки из Claude Code видны в его истории.

Программа стоит не в `C:\Program Files\Kostik-1.0` — задайте путь переменной окружения `KOSTIK_CLI`:

```
setx KOSTIK_CLI "D:\Программы\Kostik\Kostik-cli.exe"
```

В Linux плагин не нужен, сервер подключается одной командой: `claude mcp add kostik -- kostik --mcp-stdio`.

## Данные

Сама программа снимки никуда не отправляет. Но результаты проверки, которые получает Claude, уходят в модель
через интернет. Снимки пациентов и данные организатора передавайте так только с разрешением.

В плагине нет токенов, паролей и личных данных: только адрес запуска программы и текст подсказок.

## Не для диагноза

Kostik оценивает качество снимка, а не состояние пациента. Вердикт по бедру — подсказка модели.
