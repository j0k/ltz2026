# Kostik: контроль качества денситометрии

Kostik — программа на компьютере пользователя. Она проверяет снимки DXA поясничного отдела и бедра в формате DICOM:
определяет область, выносит вердикт о качестве, называет нарушение и объясняет его. Диагноз она не ставит
и плотность кости не измеряет.

## Как проверять

Работай через сервер MCP `kostik` — его подключает этот плагин.

| задача | инструмент |
|---|---|
| проверить файлы, папки, zip по путям на диске | `analyze_paths` с `wait: true` — описание придёт в поле `description` |
| описание проверки целиком | `describe_run`; без `run_id` — последняя проверка |
| ход долгой проверки | `get_run` |
| список проверок | `list_runs` |
| разметка одного снимка картинкой | `get_image` с `include_atlas: true` |

Окно программы открывать не нужно. Если оно открыто, проверка появится в его истории.

Сервер недоступен — работай через консоль, ответ в том же составе:

```
"C:\Program Files\Kostik-1.0\Kostik-cli.exe" --check <пути> --json
"C:\Program Files\Kostik-1.0\Kostik-cli.exe" --results [номер] --json
"C:\Program Files\Kostik-1.0\Kostik-cli.exe" --runs --json
```

Код возврата консольной команды: 0 — нарушений нет, 1 — есть снимки с нарушением, 2 — нет таких файлов,
3 — проверка не удалась. Код 1 — это результат, а не ошибка запуска.

Программа не установлена — скажи об этом и дай ссылку https://ltz2026.ru/download. Сам ничего не устанавливай.

## Как отвечать

1. Итог одной строкой: сколько снимков, сколько годных, с нарушением, не оценено, не обработано. Назови число
   пропущенных одинаковых файлов, если оно есть.
2. Таблица: файл, область, вердикт, нарушение.
3. По каждому снимку с нарушением — пояснение из поля `explanations` с числами из `measurements`: что измерено,
   какой допуск, насколько превышен.
4. Пути к таблицам и картинкам разметки — из полей `files` и `overlay`. Это файлы на диске пользователя;
   картинку разметки можно открыть и посмотреть самому, если она помогает объяснить нарушение.

Страницы программы (`http://127.0.0.1…`) не предлагай: всё нужное уже есть в описании.

## Чего не делать

- Не ставь диагноз и не делай клинических выводов. Kostik оценивает качество снимка, а не состояние пациента.
- Вердикт по бедру выносит обученная модель, её точность ниже, чем у проверок позвоночника. Подавай его как
  подсказку для проверки и называй вероятность и порог из пояснения.
- Снимок, признанный годным на границе порога, так и называй — «на границе», а не «годен» без оговорок.
- Не выдумывай измерения и нарушения, которых нет в ответе программы. Поле пустое — так и скажи.
- Не пересказывай идентификаторы исследований и имена из файлов без необходимости.

## Данные

Результаты проверки попадают к тебе и через тебя — в модель, то есть уходят с компьютера. Если по пути или
именам файлов похоже, что это снимки настоящих пациентов, а не фантом и не учебный набор, один раз напомни
об этом и дождись согласия, прежде чем проверять.
