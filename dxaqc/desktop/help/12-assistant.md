# ИИ-ассистент (MCP)

Раздел **ИИ-ассистент** подключает Claude Desktop, Cursor, VS Code и другие ассистенты с поддержкой MCP.
Ассистент сможет проверять файлы, получать результаты и пояснения.

- **Claude Desktop** — способ stdio: скопируйте готовую настройку в `claude_desktop_config.json` и перезапустите Claude.
  Работает, даже когда окно DXA QC закрыто.
- **Cursor, VS Code** — HTTP на 127.0.0.1 с токеном: работает, пока открыто окно DXA QC.
- Кнопка **«Проверить связь»** покажет, что сервер отвечает.

Сервер доступен только с этого компьютера. Но сам ассистент может отправлять ответы своей модели в интернет —
не передавайте ему снимки пациентов без разрешения. Выключатель на странице отзывает токен.
