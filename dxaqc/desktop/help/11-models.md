# Модели

Основная проверка работает сразу после установки: правила и модель бедра уже внутри.

Дополнительные модели (например, **голос для озвучки пояснений**) не входят в установщик и скачиваются в разделе **Модели**:

- **Скачать** — загрузка с сайта ltz2026.ru с проверкой контрольной суммы; можно поставить на паузу и продолжить.
- **Импорт из файла** — если на компьютере нет интернета: скачайте файл модели на другом компьютере со страницы
  ltz2026.ru/download и выберите его здесь.
- **Удалить** — освободить место; модель можно скачать снова.
