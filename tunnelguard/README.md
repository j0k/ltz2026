# TunnelGuard — ЛЦТ 2026, задача 05

Обнаружение посторонних объектов перед беспилотным поездом в тоннеле метро по данным 3D-лидара.
Заказчик задачи: Мостранспорт. Команда Codellake: Юрий Коноплёв, Алексей, Claude.

**Это первая версия на синтетических данных.** Реальных записей лидара у команды пока нет,
поэтому тоннель, датчик и объекты моделируются. Метрики ниже нужны для сравнения версий,
а не как обещание точности на реальном тоннеле.

## Как устроено

```
лидар -> локализация по карте -> сравнение с цифровым двойником -> кластеры -> проверка габарита -> решение
```

- `tunnelguard/sim.py` строит прямой участок тоннеля: обделку, пол, рельсы колеи 1520,
  контактный рельс, кабельные лотки, светильники и сигнальные шкафы. Эмулятор лидара даёт
  96 лучей по вертикали с уплотнением у горизонта, сектор ±26° и дальность 130 м.
  В скан добавляются шум дальности, выпадения, пыль, ошибка локализации, допуск обделки
  и неучтённые кронштейны на стенах.
- `tunnelguard/detect.py` отбрасывает точки ближе 12 см к поверхности двойника, собирает
  остаток в воксельные кластеры и проверяет вхождение в габарит поезда. Если объект в габарите
  ближе тормозного пути с запасом, решение «тормозить», если дальше, «предупредить»,
  если вне габарита, «в журнал».
- `tunnelguard/render.py` рисует вид из кабины, мини-карту сверху и панель решения.
- `scripts/make_demo.py` прогоняет оценку, рендерит кадры и пишет сценарий фильма для FilmKit.

## Запуск

```bash
python3 -m venv .venv && .venv/bin/pip install numpy pillow
.venv/bin/python scripts/make_demo.py            # оценка + кадры + films/demo/film.json
REUSE_METRICS=1 .venv/bin/python scripts/make_demo.py   # только кадры, метрики из results/metrics.json

# видео с озвучкой (FilmKit лежит отдельно)
cd ~/space/filmkit && .venv/bin/python -m filmkit build ~/exp/LTZ2026/films/demo
```

## Метрики первой версии

150 синтетических сцен, до трёх объектов в каждой, скорость 40 км/ч, тормозной путь 57 м.
Полные цифры лежат в `results/metrics.json`.

| Показатель | Значение |
|---|---|
| Полнота до 60 м | 99% |
| Полнота на всей дальности | 96% |
| Ложные тревоги | 0 на 150 сценах |
| Сумки у стен вне габарита без торможения | 76 из 76 |
| Медиана обработки скана | 103 мс на 2 ядрах CPU |

Ноль ложных тревог на 150 сценах не означает ноль на практике: по правилу трёх верхняя
граница на такой выборке около 2% сцен. Симуляция проще реального тоннеля.

## Честные оговорки

- Цифровой двойник в первой версии совпадает с геометрией симулятора. На реальных данных
  двойником станет облако точек эталонного проезда, а расстояние будет считаться через KD-дерево.
- Для кадра «сложный случай» перебирается сид сцены, пока труба и сумка не читаются
  однозначно. Сработал первый же сид из перебора, но это отбор для демо, метрики считаются отдельно.
- Кривые участки не моделируются, это следующий шаг через координаты пути по плану путей.
- Метка «похоже на человека» ставится по габаритам кластера, классификатора пока нет.
