# Пояснение решения: граф и текст

У каждого снимка на дашборде есть пояснение — как программа пришла к вердикту:

**Снимок → Область (и почему) → Метод → Проверки ТЗ → Вердикт.**

У каждой проверки — измеренное значение и норма. Зелёная проверка пройдена, красная — нарушение.
Переключатель **«граф | текст»** сворачивает граф в обычный текст; выбор запоминается для всех снимков.
