Спросить Claude

Claude отвечает по рабочей папке проекта: это копия кода стенда, скриптов, тестов и ТЗ, медицинских данных в ней нет. Вопрос и прочитанные файлы уходят в Claude, то есть во внешний сервис.

По умолчанию Claude только читает файлы. Если нужно что-то запустить или изменить, отметьте «нужно исполнение»: вопрос дождётся одобрения админа и выполнится с полными правами в рабочей папке. Каждый вопрос — новый разговор, прошлые вопросы Claude не помнит.
