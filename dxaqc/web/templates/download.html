Windows 10 и 11

  1. Скачайте .exe и запустите.
  2. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Предупреждение появляется, потому что у программы пока нет платной цифровой подписи.
  3. Следуйте мастеру установки: права администратора не нужны.
  4. Откройте Kostik из меню «Пуск». Проверить установку — ярлык «Проверка установки».

Для администраторов: msiexec /i Kostik-{{ rel.version|lower }}.msi /qn — тихая установка на компьютер, msiexec /x … /qn — удаление. Окно использует встроенный в Windows Microsoft Edge WebView2.

Linux

  1. Скачайте {{ deb.name }}.
  2. В терминале, в папке с файлом: sudo apt install ./{{ deb.name }} — система доставит нужные пакеты окна (WebKitGTK). Можно и двойным щелчком через «Центр приложений» Ubuntu; если он не справится — установите командой.
  3. Откройте Kostik из меню приложений или командой kostik.
  4. Проверка установки: kostik --selftest.

Ubuntu 22.04–26.04, Debian 12 и 13 (Python 3.10–3.14). Удаление: sudo apt remove dxaqc. Пакет не из магазина Ubuntu, поэтому «Центр приложений» может назвать издателя неизвестным: авторы — Алексей Чуркин и Юрий Коноплёв, подлинность файла проверяется по SHA-256 и подписи ниже.
